# Contributing to SalesFlow Automation Hub

Thank you for your interest in contributing to SalesFlow Automation Hub!

## Development Workflow

1. **Fork the repository** and clone your fork locally.
2. **Create a branch** for your feature or bug fix:
   ```bash
   git checkout -b feature/my-new-feature
   ```
3. **Set up the environments**:
   - Backend: Python 3.11 with FastAPI (see `backend/README.md`)
   - Frontend: Node.js 18+ with Next.js (see `frontend/README.md`)
4. **Test your changes**:
   - Run unit and integration tests locally before submitting.
5. **Open a Pull Request**:
   - Provide a concise description of your changes.
   - Wait for automated code analysis and reviews.

## Code Standards
- Follow PEP 8 guidelines for Python backend code.
- Ensure TypeScript / ESLint checks pass for the frontend.
